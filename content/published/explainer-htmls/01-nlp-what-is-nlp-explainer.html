01 · DEFINITION

Natural language vs. computer language

A natural language — English, Mandarin, Arabic — grows organically in a community: expressive, full of quirks, and often ambiguous. A computer language — Python, SQL — is rigid by design. NLP is the bridge between the two.

Natural language
"Can you grab that?"
"I'm dying to see this movie."
Flexible, contextual, ambiguous — meaning depends on who's talking and what they already know.
Computer language
SELECT * FROM movies;
if x > 0: return True
Rigid, unambiguous — one valid interpretation, strictly defined syntax.
